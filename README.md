# Maze Runner

An interactive **Maze Runner game developed in 8086 Assembly Language**.

The player controls a hero and must navigate through a maze from the starting point to the destination while passing through obstacles and completing the level within the given time.

## 🎮 Features

* 🧍 Keyboard-controlled hero movement
* 🏁 Start-to-end maze navigation
* 🧱 Obstacles and hurdles
* ⏱️ Timer using timer interrupts
* 🎯 Multiple difficulty levels:

  * Easy
  * Medium
  * Hard
* 🎮 Keyboard interrupt handling
* 🖥️ Interactive console-based gameplay
* ⚙️ Developed using 8086 Assembly Language

## 🕹️ How to Play

1. Start the game.
2. Select a difficulty level.
3. Control the hero using the keyboard.
4. Navigate through the maze.
5. Avoid or pass the hurdles.
6. Reach the destination before the timer runs out.
7. Complete the maze to finish the level.

## 🛠️ Technologies

* **8086 Assembly Language**
* Keyboard Interrupts
* Timer Interrupts
* Low-level memory and register operations
